  SECTION 1 // DESCRIPTION
< < < < < < < < < < < < < < < < < < < < < < < < < < < < < < < <

  WaraqBook est un mini site e-commerce dedie a la vente de
  livres et de fournitures de papeterie en ligne.

  Le site propose une interface moderne et responsive permettant
  aux utilisateurs de :

      >> Parcourir un catalogue de produits
      >> Filtrer par categorie, prix ou recherche
      >> Ajouter des articles au panier
      >> Passer des commandes en ligne

  SECTION 3 // INSTRUCTIONS D'UTILISATION
< < < < < < < < < < < < < < < < < < < < < < < < < < < < < < < <

  [1] Ouvrir index.html dans un navigateur (Chrome, Firefox)
  [2] Naviguer via le menu en haut de chaque page
  [3] Aller sur "Produits" pour parcourir le catalogue
  [4] Filtrer par categorie, prix ou recherche textuelle
  [5] S'inscrire ou se connecter pour passer commande
  [6] Cliquer sur [🛒] pour ouvrir le panneau panier
  [7] Remplir le formulaire de livraison et choisir
      un mode de paiement (etapes guidees)
